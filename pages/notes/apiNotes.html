Manipulating PokeAPI Data

Common ways to reshape and work with fetched data before rendering:

  • Filter: keep only matching items (type, generation, habitat).
  • Map/Transform: rename keys, compute derived values.
  • Sort: order by name, ID, height, or stats.
  • Reduce/Aggregate: totals, averages, min/max.
  • Normalize: flatten nested objects for easier UI usage.
  • Group: bucket by type or generation.
  • Merge: combine results from multiple endpoints.
  • Cache: store results in memory or localStorage.

Example (filter + map + sort)

// Get Electric-type Pokémon, then list names sorted by base speed.
fetch('https://pokeapi.co/api/v2/type/electric')
    .then(res => res.json())
    .then(data => data.pokemon.map(p => p.pokemon.name))
    .then(names => names.sort())
    .then(sortedNames => console.log(sortedNames));

Example (derive stats)

// Compute total base stats for a single Pokémon.
fetch('https://pokeapi.co/api/v2/pokemon/pikachu')
    .then(res => res.json())
    .then(p => {
        const total = p.stats.reduce((sum, s) => sum + s.base_stat, 0);
        return { name: p.name, totalBaseStats: total };
    })
    .then(result => console.log(result));

Example (normalize nested data)

// Flatten nested abilities into a simple array.
fetch('https://pokeapi.co/api/v2/pokemon/ditto')
    .then(res => res.json())
    .then(p => ({
        id: p.id,
        name: p.name,
        abilities: p.abilities.map(a => a.ability.name)
    }))
    .then(flat => console.log(flat));
